DelosDB post-modernization full cross-engine checkpoint overlay

Purpose
-------
Complete the benchmark-clean tree with a scientifically comparable full
SERVER checkpoint across:
- DelosDB Gen2-C3
- DelosDB Heap
- upstream Derby
- H2 (retained reference)
- PostgreSQL 18.4
- MariaDB 12.3.2

What this adds
--------------
1. Fixes mutation server-flag forwarding from coordinator to worker for:
   - mvccGen2A1Server
   - mvccGen2BServer
   - mvccGen2C3UpdateServer

   Older mutation plumbing forwarded sentinel mode but not these server-enable
   flags. F08/F09 exact historical numbers must therefore be re-established.

2. Adds current Gen2-C3 six-engine mutation checkpoint tasks:
   - F08 BARE INSERT_100
   - F08 PRIMARY_KEY_ONLY INSERT_100
   - F09 FRESH_INDEXED_UPDATE_100
   - F09 DISJOINT_INDEXED_UPDATE + CONTENDED_INDEXED_UPDATE
   - F10 legal BARE DELETE_REINSERT

3. Records indexed Gen2 DELETE as BLOCKED rather than bypassing the historical
   SQL-index reachability correctness guard.

4. Adds umbrella task:
   runDelosPostModernizationFullCrossEngineCheckpoint

The existing canonical Gen2-C3 sentinels remain authoritative for:
F01-F07 and F11-F13.

No production SQL/storage behavior is changed.
No benchmark thresholds are weakened.
No correctness guard is bypassed.
