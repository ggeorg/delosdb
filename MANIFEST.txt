DelosDB Gen2-C3 F04 disposable-statistics falsification overlay

Purpose
-------
Forward Derby's existing single-column unique-index statistics debug switch
into the F04 SERVER/JFR diagnostic so we can test whether the Gen2 nested-loop
plan is driven by a stale/low store row-count estimate.

Changed files
-------------
delosdb-tests/build.gradle
delosdb-tests/src/delosTestSupport/java/io/github/ggeorg/delosdb/benchmark/jdbc/DelosJdbcCrossEngineConcurrency.java

Behavior
--------
Diagnostic-only.
No production optimizer, storage, MVCC, RawStore, WAL, recovery, or durable-format changes.
The F04 diagnostic may be run with:
  -Pdelosdb.f04.refreshSimpleJoinStatistics=true
  -Pdelosdb.f04.keepDisposableStats=true

The latter becomes the JVM property:
  derby.storage.indexStats.debug.keepDisposableStats=true

and is forwarded to the actual Delos DRDA server JVMs.
