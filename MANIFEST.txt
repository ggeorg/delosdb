DelosDB Gen2-C3 F04 canonical statistics stabilization overlay

Purpose
-------
Make canonical F04 simple-join fixtures establish Delos statistics
synchronously before measurement, avoiding asynchronous/order-dependent
optimizer state after the MVCC unique-cardinality production correction.

Changes
-------
- Canonical runDelosGen2C3SimpleJoinFitness explicitly enables
  refreshSimpleJoinStatistics.
- JOIN_INDEXED_FANOUT now refreshes both parent and child Delos statistics
  when simple-join statistics refresh is enabled.
- Canonical sentinel requires the summary marker proving refresh was enabled.

Scope
-----
Harness only. No production optimizer, storage, MVCC, RawStore, WAL,
recovery, durable-format, workload SQL, or benchmark-threshold changes.
