DelosDB RCM-0/1 prepared insert overlay
=======================================

Purpose
-------
Introduce the first qualification-only RawStore Concurrent Mutation prepared-insert path.

Behavior
--------
- Snapshot complete non-stream StoreDataValue rows before Heap target-page acquisition.
- Snapshot normal B-tree insert rows before tree search and reuse them across retries/splits.
- Reuse prepared field payload bytes when producing the existing durable insert WAL payload.
- Derive a transient canonical page-native image from those unchanged durable WAL bytes.
- Apply the transient image directly during normal in-process InsertOperation.doMe().
- Recovery-created InsertOperation instances retain the inherited StoredPage decoder path.
- Unsupported/stream-backed rows conservatively fall back to the inherited serializer.

Controls
--------
- delosdb.experimental.rawStorePreparedInsert.enabled (default OFF)
- delosdb.diagnostic.rawStorePreparedInsert (default OFF)

Focused qualification
---------------------
:delosdb-tests:runDelosRawStoreConcurrentMutationPreparedInsert

Deliberately unchanged
----------------------
- RawStore WAL format and ordering
- recovery and logical undo semantics
- page format and B-tree format
- page latch model
- B-tree routing/search model
- LogToFile and group commit
- public Derby store APIs
