DelosDB F08 B-tree split-authority proof r5 module-boundary fix

Purpose
-------
Compile BTreeInsertStructuralDiagnosticTestSupport through the repository's existing
org.apache.derby.engine test-patch mechanism instead of the org.apache.derby.tests
module. This fixes the r4 compileTestJava split-package/module failure without
changing production B-tree behavior or widening production visibility.

Changed files
-------------
delosdb-tests/build.gradle

Behavior
--------
- Registers BTreeInsertStructuralDiagnosticTestSupport as an internal engine test-support source.
- Excludes that bridge from normal org.apache.derby.tests test compilation.
- Copies it into prepareRawStoreInternalTestSupportSources so compileRawStoreInternalTestSupport
  compiles it with --patch-module org.apache.derby.engine.
- Reuses the existing rawStoreInternalTestSupportClassDir already present on the split-proof task classpath.

Not changed
-----------
- No production Java code.
- No B-tree insert/split behavior.
- No RawStore/WAL/recovery behavior.
- No benchmark thresholds or workload shape.
- No new public API or module export.
