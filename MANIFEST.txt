DelosDB F08-J B-tree INSERT branch-routing snapshot experiment

Purpose:
- Extend the validated F08-I root-routing experiment with the existing immutable
  level-1 B-tree branch routing snapshots.
- Route INSERT searches root snapshot -> branch snapshot -> authoritative leaf,
  validating retained snapshots before and after leaf acquisition/search.
- Fall back to the current root-snapshot or inherited latched-root path whenever
  routing snapshots are absent, stale, or unsupported by the current tree height.
- Keep the production experiment default OFF.
- Add a focused F08-J server-JFR task using the same PRIMARY_KEY_ONLY INSERT_100
  shape and the same Heap / Gen2-status / upstream Derby comparator set as F08-I.
