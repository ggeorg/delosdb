DelosDB overlay: Gen2-C3 consolidated non-covering base-fetch experiment

Purpose:
- Test the remaining F02/F03 non-covering INDEX_TO_BASE_ROW runtime tax.
- Do not change the already-promoted materialized TABLE_SCAN CURRENT decoder.
- Do not restore rejected page-local prefetch, bounded candidate batching, cache-size tuning,
  ORDER BY removal, or projected-current-alone experiments.

Experimental property:
- delosdb.experimental.mvccGen2ConsolidatedBaseFetch.enabled
- default OFF

Candidate read-only Gen2 base-fetch path:
- Reuse one CURRENT RawStore template per base ConglomerateController / FetchProjection.
- Use the SQL valid-column FetchProjection directly for CURRENT payload fields.
- Always fetch/validate CURRENT kind and format tags.
- Always fetch row/version identity required by VisibleRow and RowLocation semantics.
- Fetch creator transaction id only when beginSequence == UNCOMMITTED_SEQUENCE.
- Fetch predecessor id/page/record only when CURRENT is not visible and HISTORY fallback is needed.
- Reuse the statement-lifetime CURRENT container and version reader already owned by the controller.
- Preserve locator-hint-first lookup and fallback container scan semantics.
- Preserve VisibleRow cloning/copy ownership; direct-to-destination materialization is intentionally
  deferred so this remains the smallest causal experiment.

Correctness:
- Adds a Gen2-C3 secondary-index -> INDEX_TO_BASE_ROW test with projected narrow reads.
- Covers committed CURRENT, writer-own uncommitted CURRENT, foreign-reader HISTORY fallback,
  repeatable-read history after writer commit, fresh CURRENT after snapshot end, and rollback.
- The old projected-current property is explicitly OFF in this test.

Performance diagnostic:
- Reuses the existing matched Phase-2K F03 decomposition.
- Explicitly requires Gen2-B1/C1/C2 and rejects projected-current/page-prefetch contamination.
- A/B lanes differ only in consolidated base fetch OFF vs ON.
- Covered projection is the negative control.
- Two-column projection exercises narrow non-covering base fetch.
- Full-row projection exercises non-covering base fetch without a projection-width advantage.
- The Phase-2K summary records consolidatedBaseFetch=true|false.
