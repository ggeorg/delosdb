DelosDB overlay: Gen2-C3 direct-to-destination base-fetch experiment

Purpose:
- Test the remaining approximately constant per-row Gen2 tax on non-covering
  INDEX_TO_BASE_ROW range execution.
- Remove only the intermediate visible CURRENT payload materialization:
    CURRENT template -> cloned VisibleRow.values() -> copyRow(destination)
  becomes:
    CURRENT template -> destination DVDs
  when CURRENT itself is visible.
- Keep HISTORY fallback on the existing VisibleRow/copy path.

Experimental property:
- delosdb.experimental.mvccGen2DirectDestinationBaseFetch.enabled
- default OFF

Production experiment:
- Applies only to read-only Gen2-A1/C1/C3 base fetches with no prefetched directory.
- Reuses the already-promoted CurrentBaseFetchDecoder and statement-lifetime resources.
- CURRENT kind/format validation, row/version identity, lazy creator fetch,
  lazy HISTORY metadata, physical RowLocation hint lookup and fallback lookup remain unchanged.
- For visible non-tombstone CURRENT rows, copy only requested payload fields directly
  from the reusable RawStore CURRENT template into caller-owned destination DVDs.
- If a destination holder is absent, clone with forced materialization before publishing it.
- Return only found/version metadata to the conglomerate controller.
- HISTORY fallback continues through the existing VisibleRow ownership path.

Correctness coverage:
- Existing Gen2-C3 forced secondary-index/base-row test now enables this experiment.
- Covers committed CURRENT, writer-own uncommitted CURRENT, foreign-reader HISTORY fallback,
  repeatable-read history after writer commit, fresh CURRENT after snapshot end, and rollback.
- Projected-current experiment remains explicitly OFF.

Matched performance diagnostic:
- Reuses the accepted Gen2-C3 one-client RANGE_SCAN_1000 diagnostic contract.
- Targets: delos_heap, delos_mvcc, upstream_derby.
- Table shape: PRIMARY_KEY_ONLY.
- Four runs per lane.
- Physical scan cost ON.
- Physical RowLocation cost ON.
- Page-prefetch and projected-current experiments OFF.
- OFF and ON lanes differ only in direct-destination base fetch.
- SQL semantic oracle ON.
