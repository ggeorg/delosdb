DelosDB Gen2-C3 F06 lazy CURRENT identity fetch experiment

Diagnostic-only experiment on top of the accepted Phase-2O F06 stack.

Changed repository files:
- delosdb-storage-mvcc/src/main/java/org/apache/derby/impl/store/access/mvcc/MvccRawStoreFormat.java
- delosdb-storage-mvcc/src/main/java/org/apache/derby/impl/store/access/mvcc/MvccRawStoreTable.java

New experimental property:
- delosdb.experimental.mvccGen2LazyCurrentIdentityFetch.enabled

Benchmark forwarding property:
- delosdb.benchmark.mvccGen2LazyCurrentIdentityFetch

Purpose:
- omit CURRENT rowId/versionId from the common visible-row FetchDescriptor;
- fetch identity only when history fallback requires rowId, row locations are requested,
  or the streaming scan must preserve its last-row position;
- leave storage format, visibility semantics, WAL/recovery, optimizer, and default behavior unchanged.

- changed MVCC production Java compiled against a flattened current repository source tree;
- DelosJdbcCrossEngineConcurrency compiled against current production/test-support sources;
- modified Java methods remain below the repository 100-line limit;
- Gradle variables are scoped locally in the existing Phase-2O task block;
- ZIP integrity, duplicate-entry, and SHA-256 checks performed after packaging.
