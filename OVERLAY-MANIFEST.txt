DelosDB Gen2-C3 RowLocation Cost Regression Matrix Overlay

Purpose
-------
Exercise the already-falsified Gen2 physical RowLocation/base-row fetch cost candidate
through the existing canonical F01/F02/F03/F04/F05/F06 server fitness tasks before
promoting the cost model to a normal default.

Production behavior
-------------------
No production cost formula is changed by this overlay.
The production feature flag remains default OFF.
This overlay changes benchmark harness plumbing only.

Benchmark propagation
---------------------
The cross-engine benchmark coordinator now forwards:
  delosdb.benchmark.crossEngineConcurrency.mvccPhysicalRowLocationCost
as:
  delosdb.experimental.mvccPhysicalRowLocationCost.enabled
into Delos MVCC embedded workers and Delos MVCC DRDA servers.

The candidate is enabled in the existing canonical Gen2-C3 fitness tasks for:
  F01 primary-key reads
  F02 primary-key range/index-only scans
  F03 projection
  F04 simple joins
  F05 multi-way joins
  F06 GROUP BY

Evidence
--------
The cross-engine server manifest and textual summary record the physical RowLocation
cost state explicitly.
