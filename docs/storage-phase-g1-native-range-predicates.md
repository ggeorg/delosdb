# Storage Phase G1 — Native Range Predicates

Status: active G predicate slice.

G1 extends the Phase F native table-scan path from equality-only predicates to
Derby range qualifiers:

```text
>, >=, <, <=
```

The route remains native Derby execution:

```text
Prepared SELECT
  -> Derby parser / binder / optimizer
  -> generated activation
  -> GenericResultSetFactory.getTableScanResultSet(...)
  -> DelosTableScanResultSet
  -> Qualifier[][] range translation
  -> DelosPredicate.range(...)
  -> EngineMvccTableAccess.scan(...)
  -> Derby ExecRow materialization
```

G1 does not add any new `VersionedStorageSqlBridge` route, regex route,
`ResultSetFactory` interface method, or generated bytecode shape change.

The executable proof is:

```bash
./gradlew verifyStoragePhaseG1NativeRangePredicates storagePhaseC7StabilizationSmoke
```

The smoke proves all four range operators and a mixed range+equality
conjunction. It also asserts the prepared SELECT path does not call
`VersionedStorageSqlBridge.tryExecute(...)`.
